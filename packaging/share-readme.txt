CheckMod {VERSION} - portable moderation checklist and AHT companion

HOW TO RUN
  Open the CheckMod folder and double-click CheckMod.exe.
  Nothing is installed. No administrator rights are needed.
  CheckMod-single-file.exe is the same app packed into one file, if you
  prefer that; it takes a second longer to start.

FIRST RUN
  A short tutorial opens automatically. Press F1 to see it again at any time.

WHAT IT DOES
  Floats on top of your moderation tools, times each case against its AHT
  target, and gives you the adherence checklist to clear before closing.
  Everything is configurable from Dev Mode (the DEV button, or Ctrl+D).

WINDOWS MAY WARN YOU
  The app is not code-signed, so Windows SmartScreen may call it an
  "unrecognised app". That is a reputation check on new files, not a verdict
  about this one. Click "More info", then "Run anyway".
  IT-APPROVAL.md in this folder is written for whoever approves software on
  your machines: what the app touches, why the warning appears, and how to
  verify every claim.

YOUR DATA
  Stays on this machine. The app contains no network code at all - the
  networking modules are excluded from the build, so the capability is absent
  rather than merely unused. No telemetry, no auto-update, and no personal
  data or case identifiers are ever recorded.
  Settings and history live in %APPDATA%\CheckMod as plain text you can read
  or delete. Dev Mode - Data - Erase all data removes everything.
